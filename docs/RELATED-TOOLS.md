# Related open-source image replacement tools

Surveyed on 2026-10-16. This is a comparison of published source, not an installed-browser acceptance test or an exhaustive catalog. Selective image replacement already exists elsewhere; the differences below concern rule scope, image types, and interaction.

| Tool | What its source does | Difference from this userscript |
| --- | --- | --- |
| [Image Replacer for Firefox](https://addons.mozilla.org/en-GB/firefox/addon/image-replacer-f3rufus/) | Its [v1.0.2 package](https://addons.mozilla.org/firefox/downloads/file/4830947/image_replacer_f3rufus-1.0.2.xpi) registers an image-only native context-menu item, saves a mapping from the exact page URL and original image URL to a replacement URL or uploaded data URL, and reapplies it on that page. It handles `<img>` elements and inline CSS backgrounds on initial application, and newly added `<img>` elements. | This is a genuine selective, persistent alternative. Its native image-only menu and Firefox Android support are useful advantages. This userscript also supports hostname-scoped rules, URL patterns or CSS selectors, computed backgrounds, schedules, fit options, and separately stored uploaded images. The add-on's observer watches added nodes, not existing image-source or background changes. Its package and store listing establish Firefox support; they do not establish Chromium support. |
| [Attributes Replacer](https://github.com/kjarmicki/attributes-replacer) | The Chromium extension applies a shared list of CSS selectors and first-matching regular-expression substitutions to chosen HTML attributes, including `img[src]`. Its observer processes newly added nodes. | It can selectively rewrite an image URL, but its inspected rule storage and dispatch are global rather than separate per-site rule sets. It is a general attribute editor, without this userscript's image picking, uploaded-image library, fit controls, or schedules. |
| [ImageReplacer userscript](https://github.com/LenAnderson/ImageReplacer) | It records selected exact `<img src>` values after Ctrl+right-click and reapplies them, including to newly added images. Its [replacement source](https://raw.githubusercontent.com/LenAnderson/ImageReplacer/master/ImageReplacer.user.js) is hard-coded to Fill Murray. | It selects which images change but does not let the user choose their replacement image. Ctrl+right-click cancels the page's usual context menu. |
| [Image Swapper](https://github.com/LincolnG4/Image-Swapper) | The Chromium extension replaces images broadly with random images from a user-managed URL list. | This is an alternative for people who want blanket, randomized replacement; that is a different rule model from choosing particular source images or elements. |

The Firefox add-on shows the practical advantage of a dedicated extension's image-only native context menu. This userscript uses userscript-manager commands. Their appearance and timing vary by manager. A Chromium or cross-browser extension could offer that interaction in the future, but would require a separate packaging and compatibility decision. The other inspected tools do not justify claiming that selective replacement itself is unique.

Credit to [f3rufus](https://github.com/f3rufus) for Image Replacer for Firefox. Its page-specific rules and image context menu are useful design references. No code from the GPL-3.0 add-on was copied into this userscript.
